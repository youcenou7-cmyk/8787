# 最後的自習室

一款網頁版第一人稱心理恐怖小遊戲。玩家扮演夜班保全，巡邏一棟舊補習班大樓（4 層樓，約 15–25 分鐘，3 種結局）。
直接用瀏覽器打開 `index.html` 就能玩（需要網路來載入 Three.js）。

## 流程對照

| 範本 | 遊戲內容 |
|---|---|
| 接班：電話或紙條交代任務和情感錨點 | 1F 保全室：讀黃主任的交接單、拿鑰匙和手電筒、接女兒小晴的電話（她也在補習班自習）。可以看監視器。 |
| 1–2 樓：正常巡邏，只有小異常 | 2F 關掉三間教室的燈。走廊盡頭閃過一個人影，203 的黑板變成「我還沒讀完」。 |
| 3 樓：空間開始不對勁，劇情真相浮現 | 陳老師說出自習室「從外面上鎖」的規定後消失。走廊開始無限循環，榜單一圈一圈地改變。主任辦公室打開，裡面有 2008 年的舊報紙和林佳穎的准考證。 |
| 4 樓：追逐和選擇 | 鎖上自習室的門後全部斷電，她從走廊另一頭過來（被手電筒照到時會變慢）。你可以往樓梯跑，或回頭把門鎖打開。 |
| 結局加最後一嚇 | A 鎖上的門（逃跑，陷入循環）・B 天亮了（開門並回答她）・C 晚自習（開門但不回答） |

## 主題

保全這份工作的核心動作是「鎖門」，結局卻要你把門打開。
陳老師警告「不要回答她」，那是大人為了自保訂的規則。真正讓她能回家的，是有人願意回答她。

## 技術

- 只有一個 HTML 檔：Three.js r128（cdnjs），所有貼圖都用 canvas 程式產生（磨石子地板、綠色牆裙、黑板、紅榜），音效全部用 Web Audio 合成。
- 用低解析度渲染（約 290px 高）加上 nearest 取樣、霧、掃描線和雜訊，做出 PS1 / VHS 的質感。
- 桌機：WASD、滑鼠、Shift、E（可長按）、F。手機：左下搖桿、右半邊拖曳看、互動按鈕。
- 想改劇情對話，在檔案裡搜尋 `say([` 就能找到。三個結局的文字在 `ENDINGS`。

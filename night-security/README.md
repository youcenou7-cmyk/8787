# 夜間警備 Night Shift

受 Chilla's Art《Night Security》啟發的原創第一人稱恐怖小遊戲（瀏覽器版，Three.js）。
所有模型、貼圖與音效皆為程式即時生成，沒有使用原作任何素材。

## 遊玩
用瀏覽器直接開啟 `index.html` 即可（電腦＋鍵盤滑鼠，建議戴耳機）。

| 按鍵 | 功能 |
| --- | --- |
| WASD | 移動 |
| 滑鼠 | 視角 |
| Shift | 奔跑（有體力限制） |
| E | 互動（打卡、開關門、開關燈、刷巡邏點、電梯…） |
| F | 手電筒 |
| 監視器中 A/D | 切換鏡頭 |
| 監視器中 R | 回報異常 |
| Esc | 暫停 |

## 流程
1. 在警衛室打卡、接聽主管田中的電話
2. 巡邏：鎖上大廳正門、刷 4 個巡邏點、關掉二樓 A/B/C 辦公室的燈
3. 回警衛室看監視器、回報異常
4. 停電 → 到一樓廁所配電箱恢復電源 → 逃回警衛室並關門
5. 盯著監視器回報異常，撐到早上 6:00（漏掉 3 次就會……）
